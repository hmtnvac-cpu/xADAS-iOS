# xADAS-iOS

Native iPhone ADAS vision prototype built with SwiftUI and AVFoundation.

## V0.1

- Rear camera live preview
- Landscape driving UI
- xADAS overlay shell
- FPS/status display placeholder
- CALIBRATE and SETTING controls

## Roadmap

1. Camera + overlay
2. Lead vehicle detection
3. Distance estimation
4. Lane detection
5. Camera calibration
6. SuperCombo integration

> Prototype only. Not a certified vehicle safety system.
